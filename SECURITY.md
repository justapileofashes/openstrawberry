# Security policy

OpenStrawberry is a local browser project with planned support for imported browser data, locally stored provider credentials, and local coding-agent execution. Please do not report vulnerabilities through public issues.

Until a dedicated private reporting address is published, use GitHub’s private vulnerability reporting feature for this repository. Include affected version, platform, reproduction steps, impact, and any proposed mitigation. Do not include real passwords, API keys, cookies, account tokens, or personal browsing data.

The project’s current security posture is documented in `docs/ARCHITECTURE.md`. Security-sensitive features such as password migration, credential vault access, agent execution, browser automation, and update signing will remain disabled or incomplete until they have dedicated review and tests.

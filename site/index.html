A local-first, open-source desktop browser with browser-native AI companions, review-first agent orchestration, and privacy-aware migration. Real Chromium browsing, not a mockup.

Work in progress — nothing to install yet. There is no stable release and there are no public downloads. The buttons below turn on by themselves the moment a signed, verified release is published.

Why the buttons are off

Every one of these must be true before a download is offered

  • ☐ Windows Authenticode signing — enforced, awaiting a certificate
  • ☐ macOS Developer ID signing and notarisation — enforced, awaiting a certificate
  • ☐ Linux artifacts verified on a Linux runner
  • ☐ macOS DMG validated on a native macOS runner
  • ☑ SHA-256 checksums published for every artifact
  • ☑ Release provenance recorded

Build it yourself

An unsigned local build is fine to run — only distribution is gated. Requires Node 24+ and pnpm 11+. 

git clone https://github.com/justapileofashes/openstrawberry.git
cd openstrawberry
pnpm install --frozen-lockfile
pnpm package
